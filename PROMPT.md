# Промт для Claude Code: сайт новой клиники за один запрос

Откройте Claude Code в пустой папке (или в любой рабочей папке), вставьте текст ниже и замените ссылки.
Лучше, чтобы в браузере Claude (встроенном или Chrome) вы были залогинены в Instagram — иначе Instagram
может не показать хайлайты и посты.

---

```text
Сделай сайт стоматологической клиники из моего шаблона.

Шаблон: https://github.com/adolfsta1in/dental_template
Instagram клиники: https://instagram.com/<аккаунт_клиники>
2GIS (если есть): <ссылка или «найди сам»>
Сайт / прайс (если есть): <ссылка или «нет»>

Склонируй шаблон в новую папку <имя-клиники>, отвяжи его от репозитория шаблона и действуй строго по
docs/NEW_CLINIC_WORKFLOW.md (справочник по файлам — docs/CUSTOMIZE.md):
1. Пройди Instagram клиники (шапка, ссылки из био, хайлайты с ценами/врачами/отзывами, последние посты)
   и 2GIS — собери название, контакты, адрес, координаты, часы работы, логотип, цвета, врачей, услуги и цены,
   FAQ, реальные отзывы. Сохрани собранное с источниками в docs/clinic-data.md.
2. Перенастрой шаблон под клинику: данные, логотип, цветовая тема под бренд, врачи, услуги, цены, тексты
   на русском и кыргызском, убери все следы демо-клиники «Арча Дент».
3. Ничего не выдумывай: чего нет в источниках — заглушка + вопрос в списке для клиники.
4. Залей данные (SEED_DEMO=false npm run db:seed), прогони тесты, lint и build, открой сайт в браузере и
   проверь главную, услуги, врачей, запись и админку, в том числе на мобильной ширине.
5. В конце дай отчёт: что сделано, откуда какие данные, и список вопросов, которые надо уточнить у клиники.

Если Instagram попросит войти — остановись и попроси меня залогиниться в браузере, пароли не вводи.
```

---

### Варианты

- **Только данные, без деплоя** — промт выше как есть.
- **Сразу с GitHub и Vercel** — добавьте в конец промта:
  `Создай приватный репозиторий <имя> в моём GitHub, запушь туда проект и подготовь деплой на Vercel
  с Postgres по разделу «Деплой» в README — переменные окружения перечисли мне, секреты не печатай.`
- **Есть файл с прайсом/фото от клиники** — положите файлы в папку проекта и допишите:
  `Прайс и фото врачей лежат в папке ./from-clinic — используй их как основной источник.`
