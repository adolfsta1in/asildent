# Шаблон сайта стоматологической клиники

@AGENTS.md

Это шаблон-продукт: сайт клиники с онлайн-записью и админкой, который перенастраивается под каждую
новую клинику. Общее описание и запуск — `README.md`.

- **Сделать сайт для новой клиники** (пользователь дал Instagram/2GIS клиники) → следуй
  `docs/NEW_CLINIC_WORKFLOW.md`; справочник по файлам с данными — `docs/CUSTOMIZE.md`.
- Данные клиники: `src/config/clinic.ts`; врачи, услуги, цены, FAQ, отзывы: `prisma/seed-data.ts`;
  темы: `src/config/themes.ts`; тексты интерфейса: `messages/ru.json`, `messages/ky.json`.
- Перед сдачей: `npm test && npm run lint && npm run build` — всё должно быть чисто.
- Логику записи (`src/lib/slots/`, `src/lib/booking/`) без необходимости не менять: она покрыта тестами и
  защищает от двойной записи.
- Время — только через `src/lib/time.ts` (часовой пояс `Asia/Bishkek`), валюта — сом.
- `npm run db:seed` удаляет все данные в БД — не запускать на базе с реальными записями.
