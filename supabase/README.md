# Демо-база AsilDent в Supabase

Проект Supabase **AsilDent** (`bzayelxvaqsaxisvgwui`, регион ap-northeast-1).

## Что в базе

- **Таблицы сайта** — те же, что в `prisma/schema.prisma`, только под Postgres (`01_schema.sql`, миграция
  `init_dental_schema`). RLS включён без политик: через публичный API Supabase данные не видны, сайт ходит
  в Postgres напрямую.
- **Данные клиники** — из `src/config/clinic.ts` и `prisma/seed-data.ts`: 4 врача, 25 услуг, графики, отзывы, FAQ.
- **Демо-записи** (все пациенты вымышлены) — 399 записей за 3 недели назад и 2 недели вперёд: каналы
  «сайт / WhatsApp / звонок / Instagram / админка», статусы, когда пациент записался, комментарии, повторные
  пациенты, выходные и особые часы врачей. Занятые 5-минутные ячейки (`BookedSlot`) пересчитаны из записей —
  уникальный индекс гарантирует, что записи к одному врачу не пересекаются.
- **Представления на русском** (миграция `readable_views_ru`, видны в Table Editor):
  - «Журнал записей» — кто, к кому, на что, откуда и за сколько до визита записался;
  - «Загрузка врачей по дням» — рабочие / занятые / свободные часы, выходные;
  - «Источники записей» — сколько записей с каждого канала и сколько доходит до визита;
  - «Пациенты» — карточка по телефону: визиты, отмены, следующая запись, первый канал;
  - «Популярные услуги».

## Пересоздать демо-записи

```bash
npx tsx supabase/demo-data.ts   # → supabase/out/static.sql и appts_*.sql
```

Даты считаются от сегодняшнего дня. Перед повторной заливкой очистить `BookedSlot`, `Appointment`,
`ScheduleException` (и остальные таблицы, если заливается `static.sql`).

## Подключить сайт к этой базе

1. Supabase → Project Settings → Database → Connection string → **Transaction pooler** (порт 6543).
2. Вставить строку в `.env` как `DATABASE_URL="postgresql://…"` (с паролем базы).
3. В `prisma/schema.prisma` поменять `provider = "sqlite"` на `"postgresql"`, сгенерировать клиент
   (`npx prisma generate`) и отметить схему как уже применённую — см. README, раздел про PostgreSQL.
   **Не запускать `npm run db:seed`** — он удалит демо-записи.
