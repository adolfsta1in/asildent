# Перенастройка шаблона под новую клинику

Документ для человека и для Claude Code. Цель — превратить демо «Арча Дент» в сайт реальной клиники:
её название, логотип, цвета, врачи, услуги, цены, график и контакты. Код трогать почти не нужно —
всё вынесено в несколько файлов с данными.

## 0. Подготовка

```bash
git clone https://github.com/adolfsta1in/dental_template.git <папка-клиники>
cd <папка-клиники>
git remote remove origin            # это новый проект, не пушим в шаблон
npm i
cp .env.example .env                # задать ADMIN_PASSWORD и SESSION_SECRET
npx prisma migrate dev
```

## 1. Какие данные собрать о клинике

| Данные | Где обычно найти | Куда вписать |
| --- | --- | --- |
| Название, короткое название | Instagram (имя профиля), вывеска | `clinic.ts` → `name`, `shortName` |
| Слоган / суть клиники | Био Instagram, закреплённые посты | `clinic.ts` → `tagline`, `description` |
| Текст «О клинике» | Посты о клинике, сайт, 2GIS | `clinic.ts` → `about` |
| Телефоны | Кнопка «Позвонить», био, 2GIS | `clinic.ts` → `phones` (первый — основной) |
| WhatsApp | Кнопка/ссылка `wa.me/…` в био | `clinic.ts` → `whatsapp` (только цифры, `996…`) |
| Telegram, Instagram | Ссылки в профиле | `clinic.ts` → `telegram`, `instagram` (без @) |
| Адрес, как найти | Био, 2GIS | `clinic.ts` → `address`, `addressNote` |
| Координаты | 2GIS / Google Maps (ПКМ по точке) | `clinic.ts` → `lat`, `lng` |
| Ссылка на 2GIS | Поиск клиники в 2gis.kg | `clinic.ts` → `twoGisUrl` |
| Часы работы | 2GIS, био, хайлайты | `clinic.ts` → `workingHours` |
| Год открытия, рейтинг | Посты «нам N лет», 2GIS | `clinic.ts` → `foundedYear`, `rating`, `patientsCount` |
| Логотип | Аватар Instagram (лучше — исходник у клиники) | `public/brand/logo.svg` + `logoUrl` |
| Фирменные цвета | Логотип, оформление постов | тема в `themes.ts` |
| Врачи: ФИО, специализация, стаж, образование | Посты «знакомьтесь», хайлайты «Врачи» | `seed-data.ts` → `doctors` |
| Услуги и цены | Хайлайты «Цены»/«Прайс», посты, сайт | `seed-data.ts` → `services` |
| Частые вопросы | Хайлайты «FAQ», комментарии | `seed-data.ts` → `faqs` |
| Отзывы | Хайлайты «Отзывы» (с согласия!) | `seed-data.ts` → `reviews` |
| Юрлицо, ИНН | У клиники | `clinic.ts` → `legalName`, `legalInn` |

**Чего не делать:** не выдумывать цены, врачей, стаж, отзывы и регалии. Если данных нет — оставить
разумную заглушку и записать в список вопросов к клинике (см. п. 8).

## 2. `src/config/clinic.ts` — данные клиники

Все тексты двуязычные: `{ ru: "...", ky: "..." }`. Если кыргызского текста нет — можно оставить `ky: ""`,
на сайте покажется русский (но лучше перевести и пометить для проверки носителем).

- `workingHours`: ключи — дни недели `"0"` (вс) … `"6"` (сб), значение `{ open: "09:00", close: "20:00" }`
  или `null` (выходной). Это часы клиники на сайте; график врачей задаётся отдельно (п. 3).
- `theme`: `"mint" | "blue" | "sand"` или id своей темы (п. 5).
- `bookingLeadMinutes` — за сколько минут минимум можно записаться (120 = за 2 часа),
  `bookingHorizonDays` — на сколько дней вперёд открыта запись, `slotStepMinutes` — шаг сетки времени.
- `mapEmbedUrl` — оставить пустым, если нет ссылки на виджет 2GIS с ID организации.

## 3. `prisma/seed-data.ts` — врачи, услуги, цены, FAQ, отзывы

- **`categories`** — категории услуг. `slug` латиницей (используется в коде seed для привязки услуг).
- **`services`** — каждая услуга:
  - `slug` — адрес страницы (`/uslugi/<slug>`), латиница через дефис (транслит: «Лечение кариеса» →
    `lechenie-kariesa`);
  - `category` — `slug` категории;
  - `name`, `short` (одна строка в прайсе), `description` (абзацы через пустую строку `\n\n`);
  - `durationMin` — длительность приёма, кратно 5 (влияет на расчёт слотов!);
  - `priceFrom` (и необязательный `priceTo`) — в сомах, целым числом;
  - `popular: true` — показать на главной (лучше 6–8 услуг).
- **`doctors`** — каждый врач:
  - `slug` (`/vrachi/<slug>`), `name`, `specialty`, `bio`, `education` (список строк), `experienceSince` (год);
  - `services` — список `slug` услуг, которые врач оказывает (на них к нему можно записаться);
  - `schedule` — недельный график: `{ 1: ["09:00", "18:00", "13:00", "14:00"] }` = понедельник 9–18,
    перерыв 13–14. Без перерыва — два элемента. День, которого нет в объекте, — выходной.
    Если реальный график неизвестен — поставить по часам работы клиники.
- **`faqs`** — вопросы и ответы.
- **`reviews`** — отзывы. Для реальной клиники — только настоящие отзывы с согласия авторов и с
  `isDemo: false` (иначе на сайте пометка «Демо»). Нет настоящих — оставьте массив пустым `[]`,
  блок отзывов на главной скроется.

В `prisma/seed.ts` есть демо-записи пациентов и демо-исключения из графика — они нужны только для показа
шаблона. Для реальной клиники запускайте seed так: `SEED_DEMO=false npm run db:seed`.

Применить данные: `npm run db:seed` (**удаляет всё в БД и заливает заново** — делать до запуска,
не на работающем сайте с реальными записями).

## 4. Логотип

1. Положите файл в `public/brand/` — лучше SVG, иначе PNG/WebP с прозрачным фоном, горизонтальный,
   высотой от 120 px.
2. В `clinic.ts`: `logoUrl: "/brand/logo.svg"`.
3. Без логотипа показывается фирменный знак (зуб в цвете темы) + название — это тоже нормально.

Favicon и картинка для соцсетей (Open Graph) генерируются автоматически в цвете темы
(`src/app/icon.tsx`, `src/app/[locale]/opengraph-image.tsx`).

## 5. Цвета

Готовые темы в `src/config/themes.ts`: `mint` (мятная), `blue` (синяя), `sand` (тёплая бежевая).
Тему можно переключать в админке → Настройки.

Своя тема под бренд: скопируйте объект темы, дайте новый `id`, добавьте его в `THEME_IDS` и подберите
цвета в OKLCH (`oklch(Светлота Насыщенность Тон)`):
- `primary` — главный цвет бренда (кнопки, акценты). Светлота около 0.45–0.55, чтобы белый текст читался;
- `primary-soft` — очень светлый оттенок того же тона (0.93–0.95);
- `background`/`surface` — почти белые с лёгким оттенком бренда;
- `ink`/`foreground` — очень тёмные (0.2–0.26).

Конвертер HEX → OKLCH: https://oklch.com. После изменения обязательно `npm test` — тест
`tests/themes.test.ts` проверит контраст WCAG AA для всех тем; если падает — затемните `primary`
или осветлите фон.

## 6. Тексты интерфейса — `messages/ru.json`, `messages/ky.json`

Обязательно для реальной клиники:
- `footer.disclaimer` («Демо-сайт: клиника, врачи и отзывы вымышлены») — удалить текст или заменить;
- `footer.license` — номер лицензии клиники;
- `home.hero.statRating` — «рейтинг в 2GIS» (если рейтинг из Google — поправить);
- `home.benefits.items` — преимущества: оставить те, что правда про клинику (3D-томограф, седация,
  детская зона и т.п.), остальные переписать;
- `about.equipment` — оборудование клиники;
- `home.reviews.demoNote` — выводится только если есть отзывы с пометкой «Демо».

## 7. Политика конфиденциальности — `src/content/privacy.ts`

Шаблон с плейсхолдерами `{{LEGAL_NAME}}`, `{{INN}}`, `{{ADDRESS}}`, `{{PHONE}}`, `{{EMAIL}}`,
`{{SITE_URL}}` — они подставляются из настроек. Текст нужно проверить с юристом клиники.

## 8. Проверка и сдача

```bash
SEED_DEMO=false npm run db:seed
npm test && npm run lint && npm run build
npm run dev
```

Проверить вручную: главная (ru и `/ky`), услуги, страница врача, полная запись через `/booking`,
админка `/admin` (запись появилась, статус меняется). На телефоне — нижняя панель «Позвонить / WhatsApp /
Записаться».

Составить для клиники список того, что нужно уточнить: данные, которые не удалось найти, цены
«примерно», график врачей, фото врачей, ссылку на виджет 2GIS, юрлицо/ИНН, проверку кыргызского текста.

Деплой — см. раздел «Деплой на Vercel» в `README.md`.
